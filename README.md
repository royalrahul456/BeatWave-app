## Features

- **Stream &amp; Offline Playback:** Play music seamlessly with background playback, offline caching, and local audio library support.
- **Beatwave Cyan-Blue Theme:** Custom Material 3 Expressive UI with dynamic artwork tinting and pure black AMOLED mode.
- **Synced Lyrics &amp; Canvas:** Real-time synced lyrics from multiple providers and animated album artwork.
- **Music Recognition &amp; Equalizer:** Built-in song recognition, custom EQ presets, and playback controls.
- **Android Auto &amp; Widgets:** Home screen widgets, Quick Settings tiles, and Android Auto support.

## Download APK

APKs are built automatically via GitHub Actions:

1. Go to the [**Actions**](https://github.com/royalrahul456/BeatWave-app/actions) tab in this repository.
2. Open the latest **Build Beatwave APK** workflow run.
3. Scroll down to **Artifacts** and download **`Beatwave-APKs`**.

---

## Build Locally

Requires JDK 21+ and Android SDK:

```bash
./gradlew assembleGmsMobileArm64Release
```
